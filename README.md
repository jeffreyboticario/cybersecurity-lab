# 🛡️ Cybersecurity Lab

Hands-on cybersecurity laboratory built on a **MacBook Air M1 (Apple Silicon)** using virtualized systems and security monitoring tools.

This repository documents my practical exercises, lab configurations, observations, and cybersecurity projects as I develop my skills in cyber threat monitoring and security operations.

## 🖥️ Lab Environment

| Component | Configuration |
|---|---|
| Host Machine | MacBook Air M1 |
| Architecture | Apple Silicon / ARM64 |
| Virtualization | UTM |
| Analyst Workstation | Kali Linux ARM64 |
| Monitored Endpoint | Windows 11 ARM64 |
| SIEM / Monitoring | Wazuh |
| Endpoint Monitoring | Wazuh Agent / Sysmon |

## 🧪 Lab Architecture

The laboratory is being designed around three main components:

**Kali Linux ARM64**  
Used as the cybersecurity analyst workstation for security testing, investigation, network analysis, and laboratory exercises.

**Windows 11 ARM64**  
Used as the monitored endpoint where security events and system activities can be generated and observed.

**Wazuh SIEM**  
Used for centralized security monitoring, log collection, event analysis, alerting, and threat detection.
